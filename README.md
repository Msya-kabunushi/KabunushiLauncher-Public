# 株主ランチャー

株主鯖（Minecraft 1.20.4 / Fabric）で遊ぶための準備をするランチャーです。

- [Releases](https://github.com/Msya-kabunushi/KabunushiLauncher-Public/releases) から `KabunushiLauncher.exe` を落として開きます（Windows 用）
- 株主鯖の Mod をそろえ、公式の Minecraft ランチャー（または Prism Launcher）で起動します
- Microsoft のアカウントには触りません（ログインは公式ランチャー・Prism がします）
- ソースコードは公開していません。再配布・改変はご遠慮ください

初めて開くと、Windows が「Windows によって PC が保護されました」と出すことがあります。そのときは「詳細情報」→「実行」を押してください。
